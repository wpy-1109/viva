# 快速开始

1. 安装 Node.js 22。
2. 在仓库根目录执行 `npm ci`，然后 `npm run build`。
3. 执行 `npm run viva`。它同时启动界面和 worker，Ctrl+C 会一起停掉。只想开界面时用 `npm start`。地址是 http://127.0.0.1:43123 ，这是运行 Viva 的那台电脑上的地址。
4. 打开总览。按“载入演示数据”会写入并同步一份标明演示的手册，然后到“提案”看差异。自动驾驶默认停止，停止之后不会因为进程重启自己开始。
5. 真实模型、GitHub、飞书和钉钉没填密钥时，导诊会直接写明缺什么，测试连接失败就失败，不会改成演示回答。
6. 真实模型在“设置”里选择“真实的 OpenAI 兼容接口”，填写 Base URL、模型名和 API key。保存后密钥不再显示。用“测试连接”看真实错误；失败时不会改用演示文本。
7. 飞书和钉钉可以保存验签密钥。出站默认关闭。没有把机器人接到真实群之前，不要把合约测试当成已经接通。

环境变量样例在 `.env.example`。把密钥留在本机，不要贴到聊天或提交到 Git。
