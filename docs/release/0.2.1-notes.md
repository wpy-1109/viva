# 0.2.1

针对 0.2.0 现成包的独立安装验收。

- 现成包执行 `npm run build` 时不再寻找缺失的 `tsconfig.json`。它说明产物已经在，并以退出码 0 结束。源码包仍会真正编译。
- `npm run backup` 和 `npm run smoke` 走已随包提供的 `dist/backup/cli.js` 与 `scripts/smoke.sh`。
- `node dist/backup/cli.js --help` 只打印说明。未知参数以退出码 2 拒绝，并且不创建备份。
- API 文档补上 `POST /api/demo/seed`、`POST /api/ask` 和 `POST /api/feedback` 的请求与鉴权说明。
- 批准较旧提案后，更新的待审文本会按新基线重算成一份可审提案，避免源文件已是新版本而界面只剩无法批准的旧提案。
- 生产依赖 `@fastify/static` 升到 10.1.12。开发依赖 `vitest` 升到 5.1.2，从而带上已修复的 `tinypool`。升级后的 `npm audit` 与 `npm audit --omit=dev` 都是 0。

本仓库在 Linux x86_64、Node v22.23.4 上重新跑过：单元测试 60 通过、1 个需要现场 DSH 的测试跳过；浏览器 5 个通过；`npm audit` 与 `npm audit --omit=dev` 都是 0 个漏洞。日志在 `artifacts/test-0.2.1-final.log`、`artifacts/e2e-0.2.1.log`、`artifacts/audit-prod-0.2.1.txt`、`artifacts/audit-full-0.2.1.txt`。

Windows 和 macOS 启动脚本仍未在对应系统上运行。Docker 仍未执行。没有真实模型或渠道密钥。
