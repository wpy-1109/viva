# Viva 0.2.0 发布就绪

这是工程验收，不是用户 UAT，也不是在使用者自己的电脑上安装过的证明。GitHub 发布没有做。

源码草稿在 Origin：`https://origin.cursor.com/git/peiy/tmp-1b2adb2c959c4694`，分支 `main`。提交以仓库 `git rev-parse HEAD` 为准。

## 这次验证

在 Linux x86_64 上：

- Node v22.23.4：`npx vitest run` 为 19 个文件通过、1 个跳过，59 个测试通过、1 个跳过。日志 `artifacts/test-0.2.0-final.log`。
- 同一次构建 `npm run build` 退出码 0。日志 `artifacts/build-0.2.0-final.log`。
- `bash scripts/smoke.sh` 在更早的 0.2.0 构建上输出 `smoke ok`。日志 `artifacts/smoke-0.2.0.log`。
- `npx playwright test` 最终 5 个测试通过。日志 `artifacts/e2e-0.2.0-final.log`。中间失败见 `artifacts/e2e-0.2.0.log`：状态文案命中多个元素，以及过期提案在发布后仍被标成不能覆盖。
- Node v24.22.3、`VIVA_DSH_LIVE=1`：先因 dump 子进程没有 `PATH` 得到 `isolation_unavailable`（`artifacts/dsh-live-0.2.0.log`），补上环境后 1 个测试通过（`artifacts/dsh-live-0.2.0-final.log`）。没有模型密钥，结果不是 completed。
- `docker` 不存在。`docker compose config` 没有执行。Compose 文件只做了人工阅读，不能说容器跑过。
- `node --check scripts/viva.mjs` 通过。`scripts/viva.cmd` 与 `scripts/viva.ps1` 只做了文本检查，没有在 Windows 上运行。

## 需求对照

| 原始要求 | 状态 | 证据 |
| --- | --- | --- |
| 本地 Markdown、GitHub 读取、URL | 已实现。GitHub 与 URL 的现场网络没有令牌或公网目标，测试是夹具和 SSRF 单测 | `tests/local-sync.test.ts`、`tests/github.test.ts`、`tests/ssrf.test.ts` |
| 持久任务、租约、停止后不自动开始 | 已实现，夹具测试。两个进程认领同一任务只有一个成功 | `tests/queue.test.ts`、`tests/claim-race.test.ts`、`tests/catchup.test.ts` |
| 提案、差异、批准、回滚 | 已实现。过期提案带基线校验，后到的提案不能覆盖已更新的已发布文本 | `tests/publish-cas.test.ts`，浏览器 `e2e/workbench.spec.ts` |
| 引用回答与反馈再进入提案 | 已实现。反馈带问题、路径和修订号，批准反馈不会改写已发布正文 | 浏览器测试与 `src/server/app.ts` 的反馈处理 |
| 模型 OpenAI 兼容 | 传输用本机 HTTP 夹具测过成功、401、坏 JSON、SSE 拒绝和超时。没有真实供应商密钥，外部现场测试不可用 | `tests/openai-fixture.test.ts` |
| 飞书 | 入站签名和官方向量解密是合约测试。出站是未签名文本载荷，默认不发送。没有真实回调 | `tests/channels.test.ts` |
| 钉钉 | 明文 HMAC 是合约测试。加密回调用文档中的 SHA1 排序签名和 AES-256-CBC，并与另一段解密代码互测。没有钉钉官方密文样本，不能称为已接通 | `tests/dingtalk-crypto.test.ts` |
| DeepSeek Harness | 已按官方 CLI 合同调用 headless，并用 `resources/dsh-text-only.patch.yml` 关闭 shell、文件、网络、子代理和工具执行器。dump 确认后才运行。不是操作系统沙箱 | Node 24 现场 dump 与 `tests/dsh-live.test.ts` |
| dsh-superagent | 未加载。其路由预设仍包含 shell。只保留 MIT 归属和“不复用”的记录 | `docs/provenance.md`、`NOTICE` |
| 中文工作台、演示、导诊 | 已实现。演示会自动同步。缺密钥时测试连接失败，不改成演示回答 | 截图 `artifacts/screenshots/` |
| Docker | 文件在仓库里。本环境没有引擎，未执行 | 本文件 |
| 备份与迁移 | 备份不含密钥；恢复会回到备份时的库。迁移在重复打开时不重复执行 | `tests/backup.test.ts`、`tests/db.test.ts` |
| 用户 UAT 与 GitHub 发布 | 阻断。没有使用者签字，也没有可用的 GitHub 发布路径 | 任务说明 |

## 仍不可用的部分

- Windows 与 macOS 的实际双击启动。
- Docker 启动。
